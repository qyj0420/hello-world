## P0.4 急停检测极性（现场约定）

| 项 | 约定 |
|---|---|
| 端子 | ART **P0.4** / DB37 pin 23，急停盒检测 |
| 极性 | **有效低按下**：物理 **高** = 急停**解除**（安全就绪）；物理 **低** = 急停**按下** |
| 软件 | `LiveHardwareOptions.SafetyReadyActiveHigh = true`（默认）：`safetyReady = physicalHigh`，`pressed = !safetyReady` |
| 监视 | `LiveEmergencyMonitor` ~10 ms 独立轮询；边沿含按下与解除；顶栏五态以硬件回读为准 |
| 仿真 | DesktopUi「急停按下/解除」仅 Fake 软件标志；实机按钮禁用 |

现场对表日志格式：`P0.4 rawDi=… physical=高|低 判定=急停按下|解除 极性=高=解除/低=按下(有效低)`。

## 状态定稿（禁止混用）

| 定稿文案 | 含义 | 不等于 |
|---|---|---|
| 已连接 | 电脑与设备通信通 | ≠ 已校准，≠ 可加压 |
| 已校准 | 电量/测距校准完成（当前相） | ≠ 可加压 |
| 可加压 | 联锁齐备，允许**非零**加压 | ≠ 仅已连接；0 kV 噪声对照不算达标 |
| 急停按下 | 急停蘑菇头按下 | 校准页要求此态（本版） |
| 急停解除 | 急停已释放 | 非零加压页要求此态（本版） |

面板：电源区须为 **电源输入** + **电源开关**。

## 高优先级条目摘要（≤10）

1. **HardwareControl/Task38：「安全联锁有效，允许加压」** — 联锁直接等同可加压（高）。  
2. **Task38Session：「双设备连接成功，可以开始测试」** — 已连接抬成可试验（高）。  
3. **Task38Session：连接成功后「可继续…步进加压」** — 重连文案暗示可加压（高）。  
4. **加压页急停灯单独「急停已解除」** — 易被当成可加压；且用词非定稿「急停解除」（高）。  
5. **加压/校准急停文案统一为「急停按下 / 急停解除」** — 现网普遍「急停已按下 / 急停已解除」（高）。  
6. **校准页未正向标明「本版需要急停按下」** — 仅有解除态警告（高）。  
7. **Localization / InternationalText：「设备就绪」** — Ready 过载，易混可加压（高）。  
8. **系统性缺失：「可加压」「已校准」正向状态文案** — 现网多有未校准/连接/急停，无完整五态（高）。  
9. **电源面板文案缺失：「电源输入」「电源开关」** — UI/说明未按定稿标出（中偏高，列入摘要因属约定必覆盖项）。  
10. **「视在电荷量」→「视在放电量」**；加压页「当前相位」→「相别」（中，摘要第 10 条合并术语一致性）。

**高优差异条数（严重度=高）：8**（上表标「高」的行；摘要第 9–10 为中/约定覆盖项。）

当前逐项状态与历史证据见 handoff.md、AGENTS.md、docs/本轮修正与验证记录_20261007_R27.md。

当前实现与边界
--------------
- .NET Framework 4.8 / WinForms / x64 主程序托管项目、采集调度、分析与报告；
  定位与结论使用项目内可追溯源码；Python 保留独立算法复核用途。运行不依赖 LabVIEW。
- 加压与量程采用冻结 R27 逻辑，不混入正在修改的 R28，也不把任务39出厂校准页面
  作为汇总软件校准页面。每轮使用页面内“确认本轮并开始”，自动模式不代签确认。
  已接入受控非零加压链；是否允许实际动作仍取决于当前设备、配置、校准及联锁状态。
  源码/离线回归通过不等于实机验收；助手不进行设备采集或输出。
- 实际 ART＋Pico 序列号组合保存本机七项设备参数，首次取消或未保存不得进入实机加压。
  首次保存即完成参数配置，不等于加压许可。加压比按最高限压与 0–5 V AO 换算；
  目标达标容差 ±2%，独立最高反馈限压及 AO 上限不随之扩大。本验证版暂不启用入口密码。
- 普通设置和页面进入不重复完整识别设备；设备断开、身份变化或通信异常仍使旧状态失效。
  校准适用性按项目和相长判断；等长可共用适用的单相或 ALL 校准，来源相别不伪造。
- 标准/竞赛缺陷模型进入实际识别链，发行模型以非语义化名称部署在安装目录外的应用专用目录。
  完整性验证和名称混淆不等于本地文件无法找到或无法逆向。
- A/B 使用主定位链，C/D 仍为独立研究复核入口；不宣称已完成全部融合或准确度验收。
  报告使用所选分析结果及保存证据；面向用户的失败提示与详细诊断分开，失败不伪造结论。
- 业务项目当前仍按 ITEM.in / CABLE.in / LOC 等既有文件读取和写入。
  独立加密容器及迁移工具的测试不表示这些消费者已迁移；旧项目不属于已加密数据。
  切换需统一读取、事务、密钥和跨机恢复设计及真实旧库验收，不自动转换用户项目。
- 默认品牌为 XIONGXIN，KEHUI 素材仅用于所选 OEM；用户提供的快捷方式图标另存
  assets/shortcuts，主快捷方式引用 256.ico，512.ico 备用，系统警告图标语义不改变。
- 安装、驱动依赖提示、防护软件提示均须明确用户交互；不关闭防护、不自动添加排除项。
  用户尚无已审核的高压安全/接线正式材料及签名条件；本人验证包须如实说明未签名、材料待审核。
  不将引导文字或上游任务自测当作汇总软件实机验收。

安全默认值
----------
首次启动默认离线模式：不安装驱动、不发现或连接设备、不重启服务、不加压。
项目、浏览、分析和报告功能仍可使用。“加压测试”和“校准测试”始终显示，但只有新建并保存、
或从项目管理器加载含 ITEM.in 与 CABLE.in 的有效项目后才启用。硬件就绪时入口标为“实机”；
没有连接硬件或未启用硬件模式时入口标为“仿真”，进入前再次明确提醒当前处于仿真状态。
实机入口会重新检查指定设备身份。源码已接入受限的 Task39 零压输入桥及环境/北斗异步提供器，
但这不代表非零高压、P0.4 生产回读、定位数据生产保存及自动加压闭环已验收。
连接状态不代表加压许可；保持既有非零高压禁用边界。环境读取的现场结果仍待试机确认。
主界面仿真只载入合成波形，不是可进行实机校准或加压的独立联调程序。
独立 Task38.ControlPanel.exe 保留已有专业调试流程，真实校准采集仍禁用；现场联调仍需安全验证。

设备资产目录
------------
发布包携带 assets\device-asset-catalog.v1.json。它只含设备与标定字段，并保留来源、编号
规则及唯一性审计。自动参数匹配必须同时取得连接器实际输出的 Pico 与 ART 序列号；不能用
Location、TransportSerial、InstanceId 或设置备注代替。1.4.1 连接器只在 ART 选择唯一，且
Pico 的网络实例与 PicoSDK 枚举结果均无歧义时输出实际序列号；否则程序显示“连接器未提供实机
序列号”，保留手工参数。只有双端唯一指向同一出厂记录时才先校验、再一次性保存并应用分压比、
电感量和直流电阻。表内校准系数只作为追溯信息，不覆盖用户设置的“校准系数修正”额外乘数。

设备“已连接/就绪”和“出厂档案已匹配”是两项独立状态。实机序列号未收录时，不会因此
判定断线、也不会擅自套用其他设备参数；界面会提示操作员进入受保护的关键设备参数设置。
校准与加压入口还要求先建立并保存，或加载一个有效项目。状态卡面向操作员使用设备/档案
术语，不显示底层连接器名称。普通用户只需日常工作入口；OEM 标识、厂家维护参数和关键
设备参数各有独立受保护入口。“专家分析”只扩展数据分析能力，不代表开放模型或硬件设置。

统一分析
--------
数据分析模块采用本地确定性算法与本地轻量 AI。学习模式下自动阈值、自动分析、自动匹配和
自动结论均暂停，由操作员接受/修正反射波、输入 PRPD 放电类型并对结论评分；样本只追加保存
在本机，超出已知分布的数据会拒绝自动建议，不上传云端，也不会在生产过程中自行重训模型。
